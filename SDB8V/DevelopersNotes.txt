What are LibVLC and LibVLCSharp?
LibVLC is the core multimedia engine that powers VLC media player - it's a C library that handles media playback, streaming, and conversion.
LibVLCSharp is a cross-platform .NET binding that wraps LibVLC, allowing you to use VLC's powerful media capabilities in .NET applications.

Installation Methods
Method 1: NuGet Package Manager (Recommended)

<!-- In your .csproj file -->
<PackageReference Include="LibVLCSharp" Version="3.6.0" />
<PackageReference Include="LibVLCSharp.WinForms" Version="3.6.0" />
<PackageReference Include="VideoLAN.LibVLC.Windows" Version="3.0.20" />

Method 2: Visual Studio Package Manager Console
Install-Package LibVLCSharp
Install-Package LibVLCSharp.WinForms  
Install-Package VideoLAN.LibVLC.Windows

Method 3: .NET CLI
dotnet add package LibVLCSharp
dotnet add package LibVLCSharp.WinForms
dotnet add package VideoLAN.LibVLC.Windows
